# Warm Tactile Visual Direction

Date: 2026-04-06

## Context

The earlier UI iterations fixed layout and flow problems, but the product still felt visually muted. Too many surfaces, text treatments, and controls shared the same soft weight, which made the interface read like a safe starter kit instead of a product with its own point of view.

For casedock, calm cannot mean flat or sleepy. The interface needs clearer hierarchy, stronger ink contrast, and more tactile controls while staying text-first and low-noise.

## Decisions

- The shared UI direction shifts from cool soft-SaaS styling to a warmer, more tactile system.
- Text should no longer default toward muted gray inside work surfaces.
- Headings, primary actions, and selected states should carry obvious visual weight.
- Primary CTA styling should feel intentional and product-grade, not generic pill buttons.
- Navigation should rely more on structure and contrast than on soft rounded fills.
- Inbox remains the first fully pushed surface and sets the tone for the rest of the product shell.

## Why

This keeps casedock aligned with the original product goals while correcting the weak feeling of the initial execution:

- calm before power
- readable at a glance
- fewer generic surfaces
- more character without noise
