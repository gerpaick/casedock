# Sharper Fizzy Controls

Date: 2026-04-06

## Context

The warmer visual direction improved the product tone, but too many controls and surfaces still relied on rounded, soft geometry. That left the interface feeling safer than intended and weakened the more playful, direct energy requested for Inbox.

## Decisions

- Buttons should use small-radius rectangular shapes instead of rounded capsules.
- `New Capture` becomes a dedicated hero accent button on Inbox.
- Status pills move from capsule geometry to sharper badge-like shapes.
- Panels, soft lists, and modal frames should use smaller corner radii so the full surface language feels more disciplined.
- Strong pastel color can appear in CTA treatments when it improves energy and clarity.

## Why

This keeps the product calm, but removes the generic rounded-starter look:

- more Fizzy-like directness
- less bubble UI
- clearer action hierarchy
