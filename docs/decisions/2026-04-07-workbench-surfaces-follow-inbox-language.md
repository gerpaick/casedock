# Workbench Surfaces Follow Inbox Language

Date: 2026-04-07

## Context

`/inbox/` became the first surface where the sharper, calmer casedock language started to feel close to final. Board, Focus, Search, and the Case workspace still worked, but they read more like an older panel-based prototype than the same product family.

## Decisions

- `Inbox` is now the reference surface for shared v1 workbench UI language.
- Board, Focus, Search, and Case should follow the same interaction priorities:
  - one dominant working surface
  - quieter secondary surfaces
  - shorter, more operational copy
  - the same sharp button, badge, row, and panel language
- This is an adaptation, not a literal layout copy:
  - each screen keeps its documented workflow and information model
  - only hierarchy, presentation, and lightweight interaction patterns should converge
- Settings adopts the same visual system, but remains a quieter utility surface rather than a focus-first workspace.

## Why

This keeps the workbench feeling like one product:

- faster scanning
- less panel repetition
- stronger next-step clarity
- calmer continuity between intake, focus, search, and execution
