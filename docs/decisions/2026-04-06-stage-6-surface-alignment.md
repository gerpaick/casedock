# Stage 6 Surface Alignment

Date: 2026-04-06

## Context

Inbox had already moved into the sharper, more tactile casedock language, but Board, Focus, and Search were still using an older pattern: many similar panels, low-contrast helper copy, and card-heavy presentation.

That made Stage 6 feel like a separate product instead of the same workbench.

## Decisions

- Board now uses stronger information hierarchy instead of a stack of equivalent cards.
- Focus now behaves like a small operational surface for setting and reviewing daily focus.
- Search results now use structured rows instead of card stacks.
- Board, Focus, and Search all reuse the same sharp button, badge, and surface language introduced on Inbox.

## Why

This keeps Stage 6 aligned with the current product direction:

- same product family across core surfaces
- less mdly panel repetition
- faster scanning
- stronger next-action clarity
