# Decision Notes

Use this directory for short decision records when implementation uncovers a product-significant gap, contradiction, or constraint that is not yet captured in `docs/specs/`.

Rules:

- Prefer updating the canonical spec first when the change is broad and stable.
- Add a decision note when the clarification is narrow, time-bound, or discovered during implementation.
- Decision notes must never silently override `docs/specs/`; if there is a conflict, update the spec as well.
